# wallet-assets

Logotipos que muestran las tarjetas de Google Wallet de nuestros clientes.
Google no admite subir imágenes: las descarga de estas direcciones.

**No borrar ni renombrar ficheros.** Si una dirección deja de funcionar, el logo
desaparece de las tarjetas ya entregadas hasta que se reapunten desde el
generador (`npm run google`).

Para cambiar un logo, súbelo con otro nombre (`-v2`) en vez de sobrescribir:
Google guarda copia de cada dirección y tardaría en ver el cambio.
